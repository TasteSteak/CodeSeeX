CodeSeeX Toast Manager

顶部居中、向下堆叠的土司提示管理器。整条卡片可点击消失，超出队列上限的提示排队等待补位。

队列规则

同屏上限 3 条

最多同时展示 3 条，其余进入等待队列；前一条消失后自动补位。

按 key 去重合并

相同 key 的提示复用同一条，刷新内容、计数 ×N 并重置计时，不重复入队。

自动消失 + 点击消失

info 4.2s、success 3.4s、warn 5.6s、error 6.8s；悬停暂停倒计时，点击任意位置立即消失。
